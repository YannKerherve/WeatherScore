1. Structure de la requête URL

https://localhost:8080/api/?type=multicorrected&phiNE=&gNE=&phiSW=&gSW=&apikey=ws_live_...

2. Paramètres de la chaîne d'appel

Variable Rôle / Description Format Attendu
phiNE Latitude du point supérieur gauche (Nord-Est). Float / Decimal
gNE Longitude du point supérieur gauche (Nord-Est). Float / Decimal
phiSW Latitude du point inférieur droit (Sud-Ouest). Float / Decimal
gSW Longitude du point inférieur droit (Sud-Ouest). Float / Decimal
zone Identifiant de zone géographique unique (Requis si type=modeltouse). String (Chaîne)
position Coordonnées GPS instantanées du navire (Requis si type=modelinmyposition). String (GPS)
apikey Clé d'authentification obligatoire liée à votre compte. String (Token)

3. Valeurs de traitement acceptées (Paramètre type)

Flux Fichiers GRIB (Binaire)
type=multicorrected
Télécharge le GRIB multimodèle après traitement et corrections algorithmiques.
type=multinotcorrected
Télécharge les modèles bruts cumulés sans filtres de correction mathématique.
type=monomodelcorrected
Télécharge le fichier du modèle dominant unique, ajusté selon ses erreurs quadratiques.
Flux Indicateurs (Texte Brut)
type=modeltouse + zone
Renvoie sous forme textuelle le modèle numérique recommandé pour la zone sélectionnée.
type=modelinmyposition + position
Renvoie l'indice de performance textuel directement extrait à la position GPS de votre navire.

4. Exemples d'implémentation shell (cURL)

Téléchargement GRIB
curl -X GET "https://localhost:8080/api/?type=multicorrected&phiNE=49.5&gNE=-0.1&phiSW=49.1&gSW=0.5&apikey=ws_live_4f8a92b3c7e10a9f" -o marine_data.grib
Requête texte (Modèle sur zone)
curl -X GET "https://localhost:8080/api/?type=modeltouse&zone=manche_centrale&apikey=ws_live_4f8a92b3c7e10a9f"
